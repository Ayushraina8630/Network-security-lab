## Notes

Experiment 2 has been added with the SHA-256 code, verification logic, and supporting README content.
Experiment 3 has been created as a placeholder structure for the next lab task.
Experiment 4 contains the OpenSSL commands, certificate validation script, generated certificate artifacts, and output screenshots.
Experiment 5 includes the Wireshark-based TLS handshake capture, analysis, and required output files.
Experiment 6 demonstrates password-based and public-key SSH authentication between Kali Linux and Ubuntu, with command scripts and output screenshots.
Experiment 7 includes the WPA2 four-way handshake analysis, Wireshark screenshots, and a saved packet capture.
Experiment 8 explains how to set up OpenPGP in Thunderbird, verify a partner's public-key fingerprint, and test encrypted, signed email and attachments.
Experiment 9 configures an IKEv2 IPsec tunnel in tunnel mode using strongSwan and verifies the established security associations, policies, protected traffic, and traffic counters.
Experiment 10 demonstrates installing and configuring Snort in pfSense, generating test traffic with Kali Linux, analyzing IDS alerts, and testing a custom TCP SYN scan detection rule.
